# Чек-листы периферийных сервисов СМП

Здесь перечислены проверки Gateway, Switch, симулятора, Transaction Logger и Web Dashboard. Подробные проверки Authorization и Card Management находятся в `test-design.md`.

## Дымовое тестирование

### Gateway

- [ ] Сервис запускается и отвечает на health-check.
- [ ] Принимает входящий запрос и передаёт его в Switch.

### Switch

- [ ] Сервис запускается и отвечает на health-check.
- [ ] Принимает запрос от Gateway.
- [ ] Передаёт запрос в Authorization и получает ответ.

### Terminal Simulator

- [ ] Симулятор запускается.
- [ ] Формирует тестовую транзакцию.
- [ ] Может использовать подготовленную карту.

### Transaction Logger

- [ ] Сервис запускается и отвечает на health-check.
- [ ] Получает результат авторизации.
- [ ] Сохраняет запись о транзакции.

### Web Dashboard

- [ ] Dashboard открывается без технической ошибки.
- [ ] Показывает сохранённую транзакцию.

### Сквозная проверка

- [ ] Простая операция по активной карте проходит через Gateway → Switch → Authorization.
- [ ] После одобрения баланс карты уменьшается.
- [ ] Результат операции есть в Logger и Dashboard.

## Критический путь

### Terminal Simulator

- [ ] Формирует платёж с активной тестовой картой.
- [ ] Передаёт платёжный запрос в Gateway.

### Gateway

- [ ] Принимает запрос терминала и передаёт его в Switch без потери данных.

### Switch

- [ ] Маршрутизирует запрос в Authorization.
- [ ] Передаёт ответ авторизации в Logger.

### Authorization и Card Management

- [ ] Для активной карты с достаточным балансом и лимитами операция одобряется.
- [ ] При успехе резервируются средства.
- [ ] В ответе есть RRN из 12 цифр и authCode из 6 символов A–Z/0–9.
- [ ] Для отсутствующей карты операция отклоняется; резервирования нет.
- [ ] Для заблокированной карты операция отклоняется; резервирования нет.
- [ ] При превышении дневного лимита операция отклоняется.
- [ ] При недостаточном балансе операция отклоняется.
- [ ] При недоступном Card Management операция отклоняется с причиной недоступности эмитента.

### Transaction Logger

- [ ] Сохраняет статус, сумму и RRN транзакции.
- [ ] Повторный поиск по RRN находит ту же транзакцию.

### Web Dashboard

- [ ] Показывает сумму, статус и RRN сохранённой транзакции.
